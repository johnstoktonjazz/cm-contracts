# cm-contracts: границы между модулями инструмента CM

Редакция 1, 11.10.2026. Автор черновиков — Роман Ковалев (CM International) через архитектора. Читают все сессии: база и ядро (Mac), верстка (облако), картограф (облако), позже расчетчик.

## Что это

Контракт — то, что пересекает границу между двумя модулями, в виде, который машина может проверить. Не описание того, как модуль устроен внутри.

Каждый контракт — папка из трех файлов:

| Файл | Что в нем |
|---|---|
| `schema.json` | JSON Schema: поля, типы, единицы, обязательность |
| `example.yaml` или `example.json` | одна настоящая запись на синтетических данных; она же тестовые данные для обеих сторон |
| `README.md` | на один экран: кто пишет, кто читает, когда меняется, что запрещено |

## Правила

1. Каждый модуль держит тест: его выход проходит `schema.json`, его вход принимает `example.*`. Тест падает — модуль не сдается.
2. Контракт меняется только с номером версии в `version` схемы и строкой в `CHANGELOG.md`: кто, что, зачем. Обе стороны подтверждают в докладе. Изменение в одиночку запрещено.
3. Поля с пометкой `confirm` в README — черновик до подтверждения владельцем; владелец подтверждает или правит в первом докладе после получения.
4. Проектных значений здесь нет: ни названий объектов, ни номеров документов. Примеры — синтетические.
5. Что не описано контрактом, модули друг у друга не читают.

## Контракты

| Папка | Граница | Владелец схемы | Состояние |
|---|---|---|---|
| `contracts/fact/` | база → верстка, картограф, расчетчик: запись факта, расчета, нормы, допущения и формат идентификаторов | база | черновик, ждет подтверждения базы |
| `contracts/slide/` | ядро и база → верстка: описание слайда | верстка (`cm-design/schema/slide.schema.json`) | действует у верстки; сюда кладется копия с версией |
| `contracts/image/` | картограф и база → верстка: картинка с сопроводительным описанием происхождения | верстка (поля), картограф (значения) | черновик |
| `contracts/overlay/` | картограф → верстка: слои карты поверх подложки в координатах места макета — контуры, точки, подписи, легенда, линейка; верстка рисует их фигурами и текстом | картограф (значения), верстка (отрисовка) | черновик |
| `contracts/geopackage/` | картограф ↔ база: слои, поля, статусы геометрии, система координат | картограф | 1.1.0, подтвержден картографом; ждет подтверждения базы |
| `contracts/tokens/` | верстка → картограф: токены стиля как единственный источник цветов, линий, шрифтов | верстка | черновик, ждет подтверждения верстки; `colors.map` — после этапа 6 |
| `contracts/norm-calc/` | база → расчетчик | база | после контрольной точки базы |

## Как получить и куда положить

Облачные сессии: `git clone` этого репозитория рядом со своим, тесты читают схемы по относительному пути или через переменную `CM_CONTRACTS`. Mac: то же. Копировать схемы внутрь модулей нельзя — тогда они разъедутся.
